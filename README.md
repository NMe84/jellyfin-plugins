# NMe84 Jellyfin Plugin Repository

This repository is a central catalogue for Jellyfin plugins maintained by NMe84.

## Adding this repository to Jellyfin

1. In your Jellyfin admin dashboard go to **Administration → Plugins → Repositories**.
2. Click **+** and paste the following URL:

   ```
   https://raw.githubusercontent.com/NMe84/jellyfin-plugins/gh-pages/manifest.json
   ```

3. Click **Save**, then go to **Catalogue** to browse and install available plugins.

> This aggregated manifest is rebuilt automatically whenever a plugin is updated.
> You can also trigger it manually from the **Actions** tab.

## How it works

Each plugin repo hosts its own `manifest.json` on its `gh-pages` branch (generated by the
plugin's release workflow). This repository's `gh-pages` branch contains an aggregated
`manifest.json` that merges all individual plugin manifests into one, so Jellyfin users
only need to add a single repository URL.
