# NMe84 Jellyfin Plugin Repository

This repository serves as a Jellyfin plugin catalogue for plugins maintained by NMe84.

## Adding this repository to Jellyfin

1. In your Jellyfin admin dashboard, go to **Administration → Plugins → Repositories**.
2. Click **+** and paste the following URL:

   ```
   https://raw.githubusercontent.com/NMe84/jellyfin-plugins/gh-pages/manifest.json
   ```

3. Click **Save** and then go to **Catalogue** to browse and install available plugins.

## Available plugins

| Plugin | Description |
|---|---|
| [Watch State Sync](https://github.com/NMe84/jellyfin-watch-state-sync-plugin) | Synchronises watch states between connected user pairs for linked TV shows |

## How the manifest is updated

`manifest.json` on the `gh-pages` branch is auto-generated by a GitHub Actions
workflow whenever a new release is published in a plugin repository. It can also
be triggered manually from the **Actions** tab of this repository.

## For maintainers: setting up a new plugin release

1. In the plugin repository, add a secret named **`MANIFEST_REPO_PAT`** containing
   a GitHub fine-grained PAT with **Contents: Read and write** permission scoped
   to *this* (`jellyfin-plugins`) repository.
2. Tag and publish a GitHub Release in the plugin repo. The release workflow will
   build the DLL, attach the zip + MD5 + `build.yaml` as release assets, and
   dispatch an update event to this repository automatically.
